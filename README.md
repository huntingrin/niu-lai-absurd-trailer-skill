# 一键牛来化

将一句普通描述、一段日常故事或一张图片，改编成一部 **牛来脸主演的 15 秒荒诞低成本国产动画电影预告片**。

它保留原始素材中最普通、最真实的部分，再加入一本正经的宏大危机、离谱转折、粗糙 3D 动画、廉价特效、严肃旁白和电影片名卡。预告片中的主要主体会始终保持固定的“牛来”卡通牛脸。

## 能做什么

输入可以是：

- 一句话，例如“我今天上班迟到了”
- 一段故事，例如“项目延期三周，所有人都在等审批”
- 一张人物、宠物、玩偶或日常物品图片

默认输出包括：

- 夸张原创片名
- 一本正经的宣传语
- 有起因、危机和高潮的荒诞剧情
- 3～5 个独立预告镜头
- 中文旁白和冲击字幕
- 低成本史诗配乐与音效
- 一段 15 秒、9:16 的实际 MP4 成片

## 效果示例

测试输入是一张“儿童抱着蓝色鱼玩偶使用电脑”的插画。Skill 将主角转换为牛来脸，并制作了《抱住地球》预告片：

> 他抱的不是鱼，是文明最后的浮力。

[下载或查看 15 秒测试视频](niu-lai-trailer-test/niu-lai-absurd-trailer.mp4)

## 安装

### 安装到 Cola

将仓库克隆到本地，并把 Skill 目录链接到 Cola 的个人技能目录：

```bash
git clone https://github.com/huntingrin/niu-lai-absurd-trailer-skill.git
cd niu-lai-absurd-trailer-skill
ln -s "$(pwd)/yi-jian-niu-lai-hua" ~/.cola/skills/yi-jian-niu-lai-hua
```

如果目标链接已经存在，请先确认它是否指向旧版本，再手动更新或替换。

SkillWatcher 会自动发现变更，新 Skill 通常会在下一轮对话中可用。

### 依赖能力

完整生成视频需要以下能力：

- 支持多参考图和局部重绘的图像生成或编辑模型
- 支持首帧图生视频的视频模型
- FFmpeg
- HyperFrames CLI，用于镜头组装、字幕、音频和最终渲染
- 可选：ListenHub CLI，用于本仓库示例采用的图像与视频生成流程

Skill 本身不绑定单一模型供应商；只要运行环境提供等价的图像编辑、图生视频和本地视频合成能力即可。

## 使用方法

安装后，在 Cola 中上传素材并直接触发：

```text
一键牛来化：我今天上班迟到了
```

```text
把我的猫牛来化，做成 15 秒荒诞电影预告片
```

```text
用这张图片生成一版牛来脸低成本国产动画预告
```

默认参数：

- 时长：15 秒
- 画幅：9:16
- 语言：中文
- 主角：视觉中心的主要主体
- 输出：片名、宣传语、剧情、旁白字幕和 MP4 成片

用户明确指定时长、画幅或主角时，以用户要求为准。多人图片无法判断主角时，Skill 会先询问要替换哪一个。

## 工作流程

1. **提炼日常核心**：保留输入中最普通的事实或动作。
2. **固定牛来身份**：读取 [`assets/niu-lai-face.png`](yi-jian-niu-lai-hua/assets/niu-lai-face.png) 作为头脸身份参考。
3. **建立荒诞剧情**：加入不必要的宏大机构、离谱道具和严肃危机。
4. **生成主体基准图**：保留原图身体、服装、姿势和构图，只重绘头脸。
5. **分镜生成**：分别生成 3～5 个短镜头，每个镜头只承担一个动作。
6. **后期组装**：加入硬切、黑场、旁白、字幕、片名卡、音乐和音效。
7. **检查与渲染**：验证主体连续性、文字安全区、音轨和实际时长后交付 MP4。

分镜生成是关键。不要把完整剧情塞进一条 15 秒图生视频提示词，否则模型容易产生梦境式形变、角色漂移和不可控转场。

## 设计原则

- 荒诞，但起因、危机和高潮必须清楚。
- 低成本感来自有意设计，不等于提示词含糊或画面不可执行。
- 牛来脸必须贯穿所有镜头，不能漂移成普通牛头、人脸或其他角色。
- 字幕和片名由后期合成，不依赖视频模型生成准确文字。
- 不复制真实电影的角色、台词、Logo、音乐或具体画面。
- 不把真实人物、品牌或事件包装成可能造成误解的新闻内容。
